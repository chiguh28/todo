## 1. このマニュアルの使い方

このマニュアルでは、**コマンド**（命令文）をターミナルに入力する操作が出てきます。

### コマンドの見方

灰色の背景で表示されている文字がコマンドです。

```
これがコマンドです
```

コマンドは**一字一句正確に**入力し、最後に **Enterキー** を押して実行します。

> **ポイント**: コマンドはコピーして貼り付けることもできます。マウスで文字を選択して右クリック→「コピー」し、ターミナルに貼り付け（⌘+V）してください。

## 2. 事前準備：必要なものを確認する

TaskFlowを動かすには以下のものが必要です。

| 必要なもの | 説明 |
|-----------|------|
| Mac（macOS 12以上推奨） | お使いのMacパソコン |
| インターネット接続 | 初回セットアップ時にダウンロードが必要 |
| Pythonバージョン3.9以上 | 手順5でインストールします |

### macOSのバージョン確認方法

1. 画面左上の **りんごマーク（）** をクリック
2. 「このMacについて」を選択
3. 表示されたバージョン番号を確認する

## 3. ターミナルを開く

**ターミナル**とは、Macに命令（コマンド）を文字で入力するためのアプリです。

### 開き方

**方法1（簡単）**: キーボードで **⌘（Command）+ スペースキー** を押す  
→ 検索バーが開いたら「ターミナル」と入力 → **Enter**

**方法2**: Finder → アプリケーション → ユーティリティ → **ターミナル** をダブルクリック

### 開いたら

黒または白の画面が開き、以下のような表示が出ます。

```
yourname@MacBook-Pro ~ %
```

この `%` の後ろにコマンドを入力します。

> **知っておくと便利**: ターミナルでは入力した文字が見えないこともありますが（特にパスワード入力時）、正常に動作しています。

## 4. Homebrewをインストールする

**Homebrew（ホームブリュー）** とは、Macに便利なソフトウェアを簡単にインストールできるツールです。Pythonをインストールするために使用します。

### すでにHomebrewがインストールされているか確認する

ターミナルで以下を入力して Enter：

```
brew --version
```

`Homebrew X.X.X` のようなバージョン番号が表示された場合は **手順5に進んでください**。

`command not found` と表示された場合は、以下の手順でインストールします。

### Homebrewのインストール

ターミナルに以下のコマンドを入力して Enter：

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

> **注意**: このコマンドは長いです。コピーして貼り付けることをおすすめします。

インストール中にパスワードの入力を求められることがあります。Macにログインするときのパスワードを入力してください（入力しても文字は表示されませんが、正常です）。

インストールが完了すると、以下のような表示が出ることがあります（Apple Silicon Mac の場合）：

```
==> Next steps:
- Run these two commands in your terminal to add Homebrew to your PATH:
    (echo; echo 'eval "$(/opt/homebrew/bin/brew shellenv)"') >> ~/.zprofile
    eval "$(/opt/homebrew/bin/brew shellenv)"
```

この場合、**表示された2行のコマンドをそれぞれ実行**してください。

### インストール確認

```
brew --version
```

`Homebrew X.X.X` と表示されれば成功です。

## 5. Pythonをインストールする

### すでにPythonがインストールされているか確認する

ターミナルで以下を入力して Enter：

```
python3 --version
```

`Python 3.9.X` 以上のバージョンが表示された場合は **手順6に進んでください**。

### Pythonのインストール

Homebrewを使ってインストールします：

```
brew install python
```

インストールには数分かかる場合があります。完了まで待ちましょう。

### インストール確認

```
python3 --version
```

以下のような表示が出れば成功です：

```
Python 3.12.X
```

（バージョン番号は3.9以上であれば問題ありません）

## 6. TaskFlowをダウンロード・解凍する

### ZIPファイルをダウンロードする

担当者からTaskFlowのZIPファイル（例：`taskflow.zip`）を受け取り、Macの任意の場所に保存します。

> **おすすめ保存場所**: デスクトップまたは書類（Documents）フォルダ

### ZIPファイルを解凍する

1. Finderで `taskflow.zip` を探す
2. ファイルを**ダブルクリック**する
3. 同じ場所に `taskflow` という名前のフォルダが作成される

解凍後のフォルダの中身は以下のようになっています：

```
taskflow/
  ├── app.py
  ├── requirements.txt
  ├── taskflow/
  ├── extensions/
  └── ...
```

## 7. ターミナルでTaskFlowフォルダに移動する

ターミナルで操作するフォルダを **TaskFlowフォルダの中** に移動します。

### 簡単な方法（ドラッグ＆ドロップ）

1. ターミナルを開く
2. ターミナルに `cd ` と入力する（`cd` の後ろに**スペースを1つ**入れる）
3. Finderで解凍した `taskflow` フォルダを**ターミナルウィンドウにドラッグ**する
4. フォルダのパスが自動入力されるので **Enter** を押す

### コマンドで移動する方法

**デスクトップに解凍した場合**：

```
cd ~/Desktop/taskflow
```

**書類フォルダに解凍した場合**：

```
cd ~/Documents/taskflow
```

### 移動できたか確認する

```
ls
```

以下のようなファイル一覧が表示されれば、正しいフォルダにいます：

```
app.py    requirements.txt    taskflow/    extensions/
```

## 8. 仮想環境を作成・有効化する（初回のみ）

**仮想環境**とは、このアプリ専用のPython環境のことです。他のアプリとの干渉を防ぐために作成します。

### 仮想環境を作成する（初回のみ）

```
python3 -m venv venv
```

少し待つと完了します。`venv` という名前のフォルダが作成されます。

### 仮想環境を有効化する

```
source venv/bin/activate
```

成功すると、プロンプトの先頭に `(venv)` が表示されます：

```
(venv) yourname@MacBook-Pro taskflow %
```

> **重要**: アプリを起動するたびに、この **有効化コマンドを実行する必要があります**。

---

## 9. 必要なパッケージをインストールする（初回のみ）

アプリが動くために必要なPythonライブラリをインストールします。

仮想環境が有効化された状態（プロンプトに`(venv)`が表示されている状態）で実行してください：

```
pip install -r requirements.txt
```

インストールが完了すると以下のような表示が出ます：

```
Successfully installed flask-X.X.X ...
```

> **注意**: このステップは**初回のみ**必要です。2回目以降は不要です。

## 10. アプリを起動する

以下のコマンドを実行します：

```
python app.py
```

以下のような表示が出たら**起動成功**です：

```
==================================================
  TaskFlow - Todo管理 + ガントチャート
  http://localhost:5000
==================================================
 * Running on http://127.0.0.1:5000
```

> **注意**: このターミナルウィンドウはアプリが動いている間、**閉じないでください**。閉じるとアプリも終了します。

## 11. ブラウザでTaskFlowにアクセスする

1. SafariやChromeなどのブラウザを開く
2. アドレスバー（URLを入力する場所）に以下を入力して Enter：

```
http://localhost:5000
```

TaskFlowのメイン画面が表示されれば**セットアップ完了**です！

## 12. アプリを停止する

TaskFlowを終了するには、アプリが動いているターミナルウィンドウで：

**Control（Ctrl）+ C** を押す

以下のような表示が出てアプリが停止します：

```
^C
```

## 13. 2回目以降の起動方法

2回目以降は以下の手順だけでOKです（手順4〜9は不要）：

**ステップ1**: ターミナルを開く

**ステップ2**: TaskFlowフォルダに移動する

```
cd ~/Desktop/taskflow
```
（保存場所に合わせてパスを変更してください）

**ステップ3**: 仮想環境を有効化する

```
source venv/bin/activate
```

プロンプトに `(venv)` が表示されることを確認する

**ステップ4**: アプリを起動する

```
python app.py
```

**ステップ5**: ブラウザで `http://localhost:5000` にアクセスする

## 14. 基本的な使い方

### メンバーを登録する（最初に行う）

1. 画面右上の **「メンバー管理」** ボタンをクリック
2. 名前と色を入力して **「追加」** をクリック
3. チームメンバー全員分を登録する

### タスクを作成する

1. 画面上部の **「＋新規タスク」** ボタンをクリック
2. 以下を入力する：
   - **タイトル**: タスクの名前
   - **担当者**: 登録済みのメンバーから選択
   - **開始日**: 作業を始める日
   - **工数（時間）**: 作業にかかる予想時間（例：16時間 = 2日分）
3. **「保存」** をクリック

### ガントチャートを確認する

- 上部のタブで **「ガントチャート」** をクリック
- 登録したタスクが自動でチャートに表示される
- タスクのバーをクリックすると進捗率（%）を入力できる

### タスクを編集・削除する

- タスク一覧の行をクリック → **「編集」** または **「削除」** を選択

## 15. 困ったときは（トラブルシューティング）

### `python3: command not found` と表示される

→ 手順5に戻り、Pythonを正しくインストールしてください。

### `brew: command not found` と表示される

→ 手順4に戻り、Homebrewをインストールしてください。  
Apple Silicon Mac（M1/M2/M3/M4チップ）の場合、インストール後に「Next steps」に表示されたPATH設定コマンドを実行する必要があります。

### `(venv)` が表示されない状態でpipを実行してしまった

→ `source venv/bin/activate` を実行して仮想環境を有効化してから、再度 `pip install -r requirements.txt` を実行してください。

### ブラウザで `localhost:5000` にアクセスしても何も表示されない

→ ターミナルでアプリが起動しているか確認してください（`python app.py` を実行中か）。  
→ ターミナルにエラーメッセージが表示されていないか確認してください。

### `Address already in use` というエラーが出る

→ すでにTaskFlowが起動しています。ブラウザで `http://localhost:5000` にアクセスしてみてください。  
→ または、別のターミナルウィンドウで **Control+C** を押してアプリを停止し、再起動してください。

### パスワードを入力しても何も表示されない

→ 正常です。セキュリティのため、パスワード入力時は文字が表示されない仕様になっています。入力後 **Enter** を押してください。

### `Permission denied` というエラーが出る

→ ファイルのアクセス権限の問題です。以下のコマンドを試してください：
```
chmod +x app.py
```
